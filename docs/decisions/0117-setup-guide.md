# 0117: A setup guide that stays until the shop is ready

Date: 2026-11-08

Replaces ADR 0116's "Finish setting up" list, which only linked away.

## Decision

**Owners and Admins get a setup guide on Today until every task is done,** then it leaves on its own. It can't be hidden, only folded to a slim bar with its progress, remembered per shop in a cookie so it's folded from the first paint.

**It's a pine card in the hero's language:** a lime ring with the share done, "Get {shop} ready", then the tasks as a numbered track (lime checks for done, the current one white) beside a white card for the task in view: its step number, why it matters, one button and an illustration. The next task left is in view by default, and any task can be picked, a done one offering to change it. On a phone the card comes before the track.

**Each task is done where it stands,** taken from Shopify's setup guide. Address, opening hours, turnaround and the Google review link open their own Settings section in a side panel, the same form as on Settings. The address task shows only the address, the turnaround task starts switched on. Inviting opens the Team page's invite form, the logo a picker (Owners only, as it's the Business's). The first Ticket opens New Ticket, the first handover the Ready Tickets. Saving closes the panel and ticks the task off from the shop's own data.

The order is the shop's: first Ticket, address, hours, turnaround, review link, team, logo, first handover.

A shop with no Ticket shows the guide in place of the first-Ticket walkthrough, which stays what an Employee sees.

Settings' layouts follow their own width rather than the window's, so a section reads the same in the panel.

## Why

A list of links sent people to pages that didn't say what they had come for, and a new shop owner who leaves Today mid-setup is the one most likely not to come back. Doing each task in place keeps them on the page that shows their progress.

A guide that can be hidden is a guide that gets hidden before the review link or the turnaround is set, which are what Customers notice. Folding keeps the page usable for a busy shop without letting the setup be forgotten. A cookie is enough for that: folding is a matter of space on one screen, not a setting.
